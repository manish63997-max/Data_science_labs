# 📊 Data Science Lab Programs

This repository contains the Python programs developed for the **Data Science Laboratory**. Each experiment demonstrates important data science concepts such as data preprocessing, exploratory data analysis (EDA), feature engineering, statistical analysis, correlation analysis, and data visualization using Python.

# ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/Data_Science.git
```

2. Navigate to the project folder

```bash
cd Data_Science
```

3. Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn
```

4. Run any experiment

```bash
python 1.University_Admission_Analytics_System.py
```

or

```bash
python 6.Climate_Change_and_Weather_Analysis.py
```
